# Visual Everyday Mechanics

Production repository for the AI-assisted instructional-animation channel.

## Locked production principle
Generative AI creates appearance, character, environments and narrative artwork.
Instructional mechanics are authored deterministically and used as ground truth/control references.
A video model may beautify the control animation, but it must not invent topology.
